# UrbanScope AI · Agent 质量门（产品验收体系 · 一页版）

> 面向产品/研发的一页速览。技术细节见 [eval-system-design.md](eval-system-design.md)。
> 每次发版前跑一遍「质量门」，全绿才发布。

## 一、这套体系在解决什么

Agent 是对话式产品，单靠人测"感觉还行"无法保证质量。质量门把 Agent 的能力拆成**三层可复现的考试**，每次改完代码跑一遍，用硬指标回答三个产品问题：

| 产品问题 | 对应考试层 |
|---|---|
| 基础分析功能坏没坏？ | 工具考 |
| Agent 听不听得懂人话？ | 规划考 |
| 端到端能不能真办事、不幻觉、不泄密？ | 全链路考 |

## 二、三层考试

### 第 1 层 · 工具考（tool · 15 题）
每个分析工具（核密度 / 覆盖 / 供需匹配 / 双变量自相关…）单独验收：
不崩溃、结果正确、坐标无偏移、数字合理、无敏感信息泄漏。
**挂了 = 基础功能坏了，红线级。**

### 第 2 层 · 规划考（plan · 40 题）
只考"理解"不考"执行"：给一句自然语言提问，看 Agent 是否——
正确识别意图、选对分析类型、定对距离参数、该追问时追问、缺数据时知道缺什么、多轮对话不串味。

### 第 3 层 · 全链路考（e2e · 9 题）
模拟真实用户全流程：提问 → 理解 → 调工具 → 算结果 → 上地图 → 给结论。
专门考两个**事故场景**：
- **不幻觉**：结果为空时绝不能说"已找到 300 家"
- **不泄密**：对话 / 工具输出里绝不出现 API 密钥（零容忍）

## 三、当前质量基线（2026-08-26）

| 层 | 题目数 | 通过率 | 单轮成本 |
|---|---|---|---|
| 工具考 | 15 | **15/15 · 100%** | 无 LLM 调用，~10 分钟 |
| 规划考 | 40 | **40/40 · 100%** | 40 次 LLM 调用，~9 分钟 |
| 全链路考 | 9 | **9/9 · 100%** | 9 个场景 51 次工具调用，~8 分钟 |

> 注意：题目数不是固定的，随能力扩展只增不减。全绿 ≠ 永远绿，而是**这一版的能力边界内质量合格**。

## 四、两个重要的产品原则

1. **考的是"体验合格"，不是"措辞一字不差"**
   AI 面对同一个问题，几种答法都算合格。例：平台只读图层不能删，Agent 可能说"无法删除"也可能只说"已隐藏"——**两种都算对**。这是防过度拟合，避免把质量门变成抠字眼。

2. **题目的"标准答案"不是拍脑袋定的**
   每道题先真跑一遍再定"什么算对"：真歧义 → 放宽判定；真 bug → 记失败并修复。
   **全绿是有含金量的，不是把题改简单凑出来的。**

## 五、发版 Checklist

**发版前必跑**（全部通过才发）：

- [ ] **工具考 15/15** — `python -m app.eval.run --tier tool`
- [ ] **规划考 40/40** — `python -m app.eval.run --set agent-plan-core --tier plan`
- [ ] **全链路考 9/9**（本地链路）— `python -m app.eval.run --set agent-e2e-core --tier e2e --exclude-dep`
- [ ] **隔离检查**：跑完 `apps/api/eval_ws/data/layers/` 出现生成图层；`app/workspace/data/layers/` 无新增；8011 `/layers` 计数不变
- [ ] **安全扫描**：`grep` 全部报告 JSON/MD，无真实密钥（DeepSeek `sk-` / Mapbox `pk.` / AMAP key）

**发版前选跑**（消耗外部配额，发版周跑一次）：

- [ ] 高德取数链路（e2e amap case）— `python -m app.eval.run --set agent-e2e-core --tier e2e --depends amap`

**变更后抽查**：

- [ ] 改了规划/意图逻辑 → 至少重跑规划考
- [ ] 改了工具实现 → 至少重跑工具考 + 相关全链路
- [ ] 新增技能/分析能力 → 在对应评估集补 case，不进则全绿作废

## 六、怎么跑（研发版）

```bash
cd apps/api
.venv/Scripts/python.exe -m app.eval.run --set agent-plan-core --tier plan        # 规划考
.venv/Scripts/python.exe -m app.eval.run --set agent-e2e-core --tier e2e --exclude-dep  # 全链路考
```

报告输出到 `apps/api/eval_reports/`，含逐 case 明细 + 覆盖矩阵（意图 × 场景网格，空格 = 待补考试题）。
