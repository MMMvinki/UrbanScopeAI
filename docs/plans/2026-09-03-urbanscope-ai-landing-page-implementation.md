# UrbanScope AI Landing Page Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build an independent, responsive competition Landing Page for UrbanScope AI that explains product value, proves the Agent × Tools × Skills × Memory mechanism, and presents three replaceable video case studies.

**Architecture:** Create a standalone React + TypeScript + Vite app in `apps/landing` so the existing `apps/web` workbench remains untouched. Keep marketing copy and case metadata in one typed content module, compose the page from small presentational sections, use native browser APIs for scrolling and reduced-motion behavior, and read the workbench URL from `VITE_PRODUCT_URL`.

**Tech Stack:** React 19, TypeScript, Vite, CSS, Lucide React, Vitest, Testing Library, jsdom.

---

## Prerequisites and execution boundaries

- Execute this plan in a dedicated Git worktree created from the current `main` branch.
- Read `docs/plans/2026-09-03-urbanscope-ai-landing-page-design.md` before implementation.
- Do not change `apps/web` routes, startup behavior, API code, or existing product styling.
- Treat the three scenario videos as optional assets. The page must remain complete when no video exists.
- Do not claim that building morphology, full population profiling, or function-mix analysis is a one-click built-in Skill. Describe these as analyses the Agent can compose from data and Tools.
- Keep Agent evaluation and run archives out of marketing copy.
