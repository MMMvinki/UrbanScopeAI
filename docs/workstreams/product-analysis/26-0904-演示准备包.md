## 2. 路由流程图（关键词 = 非 LLM，优先级钉死在 route_analysis_request 内）

```
问句 →
 ① R-COMPREHENSIVE  （词: 现状分析/整体分析/综合现状/能做什么…）
      → 按序 5 模块：活动 → 商业供给 → 商业×活力 → 公服 → 人口
        （商业×活力需前置活动+商业都完成，否则 STOP_PREREQUISITE_BLOCKED）… 不含全区可达
 ② R-THEME-*（全家桶）  需命中区域词之一（区域/片区/这个区/这里/当地/区内…）
      ├ R-THEME-COMMERCIAL    （区域+商业主题，无 供给/分布/密度/集聚/格局/画像 精确词）
      │    → 3 模块按序：商业供给 → 商业×活力 → 全区地铁可达(rail_network)   ★唯一真多模块
      ├ R-THEME-PUBLIC-SERVICE（区域+公共服务/公共设施，无 设施/分布/画像/资源分布 精确词）→ 公服
      ├ R-THEME-POPULATION     （区域+人口/人群/居民，无精确人口词）→ 人口
      ├ R-THEME-ACTIVITY       （区域+活动/活力，无精确词）→ 活动
      └ R-THEME-REACHABILITY   （区域+地铁/轨交/可达，无 覆盖率/等时圈/出入口/步行可达/站/可达率 精确词）→ 全区可达
 ③ R-POPULATION-PROFILE    （精确人口词 画像/结构/职住比/人口情况…）
 ④ R-COMMERCIAL-X-ACTIVITY （商业 + 活动/昼夜）
 ⑤ R-RAIL-NETWORK-REACHABILITY （全网词：可达率/难达区/难达/覆盖/所有地铁站/全区地铁…）★不含单字「地铁」
 ⑥ R-COMMERCIAL-RAIL-ACCESSIBILITY （商业 + 地铁/轨交/等时圈/出入口/步行可达 → ≤5 代表出入口口径）
 ⑦ R-PUBLIC-SERVICE （公共服务/设施/教育/医疗/体育/便民/应急…）
 ⑧ R-COMMERCIAL-SUPPLY （纯商业）
 ⑨ R-ACTIVITY-TEMPORAL （纯活动）
 ⑩ None → 交回自由 Planner（结果不稳定）—— 演示风险区
```

**语义 = 关键词匹配非 LLM**，漏词/歧义词直接掉 ⑩。已实测会漏的句子（演示时避开或已列 P1 补路由）：「学校和医院分布」「养老和文化设施」「全面分析一下」「这里住的和工作的是什么人」「这个片区地铁步行覆盖」（`地铁步行覆盖` 不匹配子串 `地铁覆盖`，且带精确词 `覆盖` 挡掉主题组）。

双口径分流提醒：**全区可达(全网)** 与 **商业×轨交(单走廊 ≤5 口)** 靠词表区分——「可达率/难达/覆盖/所有站/全区」进全网；「商业+出入口/等时圈/步行可达」进单走廊。带区域词的商业+可达句会被 R-THEME-COMMERCIAL（全网可达）截走，不会进单走廊。
