# 26-0831 数据目录接入 · 交付说明

> 分支 `feature/0830-data-folder`（未 push）。文件接入/管理功能分三阶段，全部完成。

## 1. 完成了什么

区分「数据目录（发现了哪些数据）」≠「地图图层（已加载可分析）」，三个阶段：

**第一阶段 · 只读发现**
- 统一「添加数据」弹窗（上传文件 / 链接本地目录两个 tab），原生文件夹选择器点选目录。
- 只读扫描 + 按子文件夹**目录树**逐级展开；四态标注（可直接启用 / 仅可查询 / 暂不可用 / 已发现）；显示格式/大小/字段/坐标/几何/原因。
- 链接目录自动记白名单（本机单用户即授权），只拒绝整块磁盘；多目录各自独立、可取消链接。

**第二阶段 · 小数据启用 + GDB + 大型数据**
- 可直接启用的数据一键启用为项目图层（`source=folder`），进地图、可被 `list_datasets` 发现。
- File GDB 用 fiona OpenFileGDB 驱动展开为「图层文件夹」，内部图层独立识别/启用。
- 大型矢量数据（>10 万要素或 >120MB）标「仅可查询」，点「预览启用」流式抽稀到 5 万要素，不全量加载。

**第三阶段 · 下载目录**
- 「下载位置」设置：联网取数（OSM/高德/datasource）默认落盘到指定本地文件夹，自动白名单 + 链接为数据源，下载后自动重扫，统一进左侧数据面板。

**面板交互优化**
- 数据目录 + 图层列表统一滚动（数据多时不再被裁掉，滚动条加宽可见）。
- 左侧面板右边缘可拖动调宽（260~720px，持久化），给地图让空间或看全内容。
- 「本地数据目录」分区可折叠收起，给图层列表腾空间。

## 4. 已知限制

- 大型矢量数据抽稀预览（抽到 5 万），非完整加载；真正按范围/字段查询留第三步。
- 启用会在 workspace 生成图层 GeoJSON 副本（与现有图层同机制），原始数据不改。
- CSV 坐标列识别 ≠ 坐标系转换：按 lon/lat 当 WGS84 读，GCJ-02/BD-09 待统一转换。
- folder 图层重启后 `source` 归一为 `uploaded`（恢复机制只从 GeoJSON 重建元数据），仅影响来源徽章。
- 下载目录数据靠「链接目录 + 启用」使用；Agent `register_layer` 仍限定 workspace。
- 本机绝对路径只存本机 workspace 配置（已 gitignore），换机需重新链接/设置。
