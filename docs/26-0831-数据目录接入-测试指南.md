# 26-0831 数据目录接入 · 测试指南

> 手动测试覆盖三阶段：只读发现、小数据启用（含 GDB/大型数据）、下载目录。

## 0. 启动

双击项目根目录 `启动平台.bat`（自动清旧后端 + 开浏览器）。浏览器用 **`http://127.0.0.1:5175`**（不是 localhost）。改代码后 VS Code 按 `Ctrl+Shift+F5` 打开测试页。

## 1. 只读发现：链接 + 目录树

1. 打开「数据图层」面板 →「本地数据目录」分区。
2. 点「链接目录」（或「添加数据」→「链接本地目录」tab）→「浏览文件夹…」选 `04-乐活大道GIS数据` →「链接并扫描」。

**验收**：路径自动填好；出现目录树（00-原始数据/01-加工数据/02-GIS工程…）逐级展开，不平铺 140 多项；每个数据有状态徽章，点开看字段/坐标/警告。

## 2. 小数据启用

展开到这三个点「启用」：

| 数据 | 预期 |
|---|---|
| 地铁出入口 subway_entrance | 上地图 1159 点，EPSG:4326 |
| 昼夜客流 passenger_..._bd09_to_wgs84 | 上地图 3183 点 |
| 商业资源 商业资源Export_Output_46 | 上地图 103659 点（稍慢，正常） |

**验收**：按钮变绿色「已启用」；地图出图层；「我的数据」出现同名图层；重启后仍在。

## 2.5 GDB 展开

展开 `02-GIS工程 / 乐活大道数据库.gdb`：

**验收**：gdb 不再是黑盒，展开成内部 55 个图层；`深圳POI`(1984)、`subway_entrance`(477) 能完整启用；`gis_osm_roads_free_1`(85 万) 标「仅可查询」可「预览启用」。

## 3. 大型数据「预览启用」（抽稀，不全量加载）

展开 `00-原始数据 / POI全量 / 深圳市2024POI.csv`（285MB）：

**验收**：状态「仅可查询」，按钮是「预览启用」；点后几秒上地图，图层名带「（抽稀预览）」，约 5 万要素（不是 94 万）；浏览器不卡、没全量加载；展开详情「行数空」+警告「文件较大，未统计行数」。

> 扫描时零预览：链接目录只读表头/元数据，不读数据行。只有点「预览启用」才抽稀。

## 4. 下载目录（第三阶段）

1. 数据面板「本地数据目录」分区顶部「下载位置」→ 点「设置」→「浏览文件夹」选一个目录（如新建 `D:\下载数据`）→「设为下载目录」。
2. 在对话框让 Agent 联网取数，例如：

```
下载深圳市南山区的地铁站 POI（用高德），保存为图层。
```

**验收**：
- 下载的文件落在你设置的下载目录（不是 workspace）；
- 下载后「本地数据目录」里出现「下载数据」源，里面有刚下载的数据，可查看/启用；
- 面板顶部「下载位置」显示你设置的目录。

## 5. Agent 测试提示词（先启用地铁出入口）

```
列出当前项目里所有可用的数据图层，并说明每个图层的来源、要素数量和几何类型。
```

```
乐活大道范围内有多少个地铁出入口？统计一下，并在地图上显示它们。
```

**验收**：Agent 通过 `list_datasets`/`get_dataset_schema` 找到 `subway_entrance`，回答基于真实要素数（1159），不是编造值。

## 5.5 面板交互（滚动 / 调宽 / 折叠）

1. 链接多个目录、启用几个图层，让「本地数据目录」树和图层列表都变长。
2. **滚动**：面板右侧出现滚动条，能上下滚到底，内容不被裁掉。
3. **调宽**：鼠标移到面板右边缘，出现左右拖动光标，拖宽/拖窄面板（地图跟着变大/变小），刷新后宽度保持。
4. **折叠**：点「本地数据目录」标题行，整块数据目录收起（给图层列表腾空间），再点展开。

## 6. 预期内的边界

- 商业资源（103k 点）启用会卡几秒（阈值内允许）。
- folder 图层重启后来源徽章可能显示「上传」而非「目录」，不影响显示/分析。
- CSV 启用按 lon/lat 当 WGS84 读，GCJ-02/BD-09 暂未转换。
