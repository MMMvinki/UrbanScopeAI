# UrbanScope AI 比赛展示分析能力建议

> 基于《乐活大道_数读城市分析》（60 页）与《福田总设—大数据专题研究报告》（78 页）的内容提炼，并与 UrbanScope AI 当前 PRD、Demo 脚本和已有 Skills/Tools 进行对照。

## 1. 一句话结论

比赛展示不建议把几十项指标做成“城市体检大屏”，而应展示 UrbanScope AI 如何把一句规划问题转成一条可追溯分析链：

**数据检查 → 通用空间分析 → 专业规划 Skill → 问题定位 → 原因解释 → 方案模拟与行动清单。**

最值得作为主线的题目是：

> **哪些高需求人群没有被公共服务和公共空间有效覆盖，为什么，优先应在哪里补设施或改善空间？**

这个题目可自然串联人口、活力、设施、交通、公共空间、用地建筑和更新潜力，并能同时表现通用分析能力与专业规划判断。

## 2. 两份报告分别怎样做数据分析

| 对比项 | 《福田总设—大数据专题研究报告》 | 《乐活大道_数读城市分析》 |
|---|---|---|
| 报告定位 | 大数据辅助总体城市设计的探索性专题 | 面向“乐活”目标的现状体检、品质诊断和策略支撑 |
| 基础框架 | 数据源 → 三维形态/业态/外部空间/人群 → 可达性 → 生活圈 → 活力影响因素 | 现状六层面 → 六大领域、48 项指标 → 空间与品质评价 → 问题总结与国际对标 |
| 主要分析对象 | 建筑形态、POI 职能、道路公园、人口画像、通勤、生活圈、城市活力 | 人群、用地建筑、公服、交通、产业、更新潜力，以及运动、宜居、公共空间、文商旅等专题 |
| 典型方法 | POI 密度与分类、人口热力、500m 缓冲与 5 分钟路网范围对比、设施叠加、活力与容积率/覆盖率/POI 的关联 | 静态覆盖与动态等时圈、供需耦合、街道界面加权、设施/公园品质分级、住房负担、低效空间盘点、更新潜力研判 |
| 典型输出 | 分布图、热力图、可达范围、生活圈综合等级、活力关联比例 | 指标卡、分类统计、覆盖率、品质地图、错配区、短板清单、体检结论、标杆对比 |
| 主要价值 | 说明“城市空间和人群活动有什么关系” | 说明“资源是否优质、公平、可达，问题在哪里，如何转化为规划议题” |

### 两份报告共同的高频分析链

1. **盘底数**：数量、面积、占比、等级、类型、结构。
2. **看分布**：点位、密度、集聚区、热点、空间梯度。
3. **算可达**：服务半径、最近距离、真实路网 5/10/15 分钟等时圈。
4. **看人群**：常住/就业人口、年龄学历收入、职住流动、工作日/周末和昼夜活力。
5. **做匹配**：设施供给与人口需求、设施密度与活力、轨道覆盖与商业/文化资源。
6. **找原因**：与容积率、建筑密度、功能混合度、POI 密度、站点、空间品质等因素叠加。
7. **下结论**：识别盲区、错配区、低效区、潜力区，形成分区分级和行动建议。

### 高频分析方法及可复用价值

| 方法 | 报告中的用法 | UrbanScope AI 的标准化方式 |
|---|---|---|
| 描述统计与分类汇总 | 设施、企业、住房、公园、道路数量和结构 | 自动识别字段、分组统计、占比、排名、异常值和图表 |
| 核密度/热点 | POI、人群、商业文化设施集聚 | KDE 密度面、热点分级、峰值和密度洼地识别 |
| 空间聚类 | 识别商业、设施或事件簇群 | DBSCAN/K-Means，输出簇、中心、规模和噪声点 |
| 静态覆盖 | 300m/500m/800m/1000m 服务半径 | 米制缓冲、与居住用地/人口网格相交，输出覆盖率和盲区 |
| 路网等时圈 | 5/10/15 分钟步行可达 | 基于真实路网的步行/骑行/驾车等时圈，并与静态半径对照 |
| 最近距离 | 居住、产业到站点或设施距离 | 每个对象最近设施距离、均值/分位数、超阈值对象清单 |
| 功能混合度 | 12 类 POI 的混合度 | Shannon 熵与标准化混合度，输出高/低混合区 |
| 供需匹配 | 设施覆盖与人口需求对照 | 供给强度/需求强度、短缺指数、服务公平性和错配区 |
| 时空活力 | 工作日/周末、昼夜人口热力 | 分时热力、时序曲线聚类、日夜比、工作日—周末差异 |
| 耦合/四象限 | 人群活力与设施、商业、文化、轨道匹配 | 高需求低供给、低需求高供给等四象限分类 |
| 加权品质评价 | 街道界面、公园品质、综合指标 | 权重可配置、指标标准化、分级地图和敏感性分析 |
| 多因子潜力评价 | 建筑年限、质量、权属、更新项目等研判潜力 | 约束条件掩膜 + 多指标综合评分 + 优先级和原因解释 |

## 3. UrbanScope AI 应展示的 8 个分析维度

### 3.1 人口、职住与时空活力

| 项目 | 内容 |
|---|---|
| 具体分析 | 常住/就业人口总量和密度；年龄、学历、收入、消费等画像；重点人群分布；常住人口工作地与就业人口居住地；职住比和通勤流向；工作日/周末、昼夜活力变化；高活力、低活力和潮汐型片区识别 |
| 所需数据 | 人口网格及人口属性、就业人口、OD/通勤数据、手机信令或分时热力、街道/社区边界、居住与就业空间 |
| 核心方法 | 分组统计、KDE、OD 矩阵、职住平衡指数、时序曲线聚类、热点与冷点分析 |
| 分析目的 | 回答“服务谁、人在何处、何时活跃、居住和就业是否错位” |
| 展示成果 | 人口画像卡、人口/就业双热力图、通勤流向图、昼夜切换地图、重点人群短板清单 |
| 当前适配度 | **部分已具备**：密度、KDE、叠加、聚类可直接用；人口画像、OD 和时序活力建议封装为专业 Skill |

### 3.2 现状用地、建筑与城市形态

| 项目 | 内容 |
|---|---|
| 具体分析 | 用地面积与结构；土地权属；建筑功能、面积、高度、层数、年代、质量；容积率、建筑覆盖率；开发强度梯度；功能密度与混合度；形态指标与活力的关联 |
| 所需数据 | 用地/地块面、建筑轮廓与高度/层数/年代/质量、权属、POI、人口活力、规划控制线 |
| 核心方法 | 空间汇总、FAR/建筑密度计算、分级统计、Shannon 混合度、网格叠加、空间相关或回归 |
| 分析目的 | 识别高强度、低效、单一功能、老旧和形态—活力不匹配地区 |
| 展示成果 | 用地结构卡、建筑高度/年代/质量地图、形态剖面、混合度地图、形态—活力解释图 |
| 当前适配度 | **通用计算可组合，缺专题编排**：建议新增 `urban_morphology` Skill |

### 3.3 公共服务设施与 15 分钟生活圈

| 项目 | 内容 |
|---|---|
| 具体分析 | 教育、医疗、养老、文化、体育、商业等设施数量/等级/类型；静态服务半径覆盖；真实路网 5/10/15 分钟可达；覆盖人口与居住用地；高需求低供给区；边缘地区与重点人群公平性；新增设施情景模拟 |
| 所需数据 | 设施点及类型/等级/容量、人口网格、居住用地、社区边界、步行路网、出入口、河流/铁路/快速路等阻隔 |
| 核心方法 | coverage、isochrone、nearest distance、supply-demand、空间叠加、服务盲区、可选 2SFCA |
| 分析目的 | 从“有没有设施”升级为“谁能真正到达、供给是否匹配、哪里优先补齐” |
| 展示成果 | 静态圆与真实等时圈对照、覆盖率卡、未覆盖高人口区、设施短板排名、新增点位前后覆盖率变化 |
| 当前适配度 | **最成熟、最适合主线**：已有城市体检、公服评估、15 分钟生活圈 Skills 和相关真 GIS 工具 |

### 3.4 道路交通与综合可达性

| 项目 | 内容 |
|---|---|
| 具体分析 | 路网等级、密度、交叉口密度、断头路与阻隔；公交/轨道站点覆盖；站点出入口与社区/公园/产业的最后一公里；目标地真实时间成本；轨道覆盖与设施/商业密度错配 |
| 所需数据 | 道路中心线和等级、步行路网、交叉口、公交与轨道站点/出入口/线路、交通流量/OD、设施和用地数据 |
| 核心方法 | 路网指标、等时圈、最近距离、网络最短路、中心性、站点覆盖与耦合四象限 |
| 分析目的 | 识别“直线很近但实际难到”、交通断点、站城脱节和轨交潜力未转化地区 |
| 展示成果 | 500m 缓冲—5 分钟等时圈对比、最后一公里盲区、轨交—功能错配图、问题路段清单 |
| 当前适配度 | **核心能力已具备**：等时圈、覆盖、最近距离可用；路网中心性和断头路识别建议扩展 |

### 3.5 宜居性与住房可负担性

| 项目 | 内容 |
|---|---|
| 具体分析 | 住房类型、面积、年代、老旧程度；公共住房比例；人均住房面积；收入水平；房价/收入比、租金/收入比；居住成本与公共服务、交通、环境品质的综合评价 |
| 所需数据 | 居住用地/小区、住宅建筑面积与年代、公共住房、人口与收入、房价、租金、公服、交通、绿地环境数据 |
| 核心方法 | 分类统计、空间匹配、房价收入比、租金收入比、指标标准化、综合宜居指数 |
| 分析目的 | 识别“条件好但不可负担”“成本高但服务弱”“老旧且配套短缺”等宜居短板 |
| 展示成果 | 住房结构卡、老旧住区地图、居住负担地图、宜居性四象限和重点改善社区 |
| 当前适配度 | **需新增专业 Skill**；基础统计和叠加可复用现有工具 |

### 3.6 公园、公共空间与步行环境品质

| 项目 | 内容 |
|---|---|
| 具体分析 | 公园数量、分类、面积和人均指标；公园入口真实可达；公园设施、全龄友好与亲水体验；街道绿视率、天空可视因子、活力界面、人行空间比例；桥下、屋顶、平台、广场等低效公共空间盘点及可达性 |
| 所需数据 | 公园边界和入口、设施清单、人口/居住、路网、街景、建筑界面、人行道、公共空间地块及现状调查字段 |
| 核心方法 | 可达性、品质规则评分、街景语义分割、加权评价、聚类、公共交通覆盖和供需耦合 |
| 分析目的 | 同时回答“有多少、能否到、好不好用、是否与人群匹配、哪里可盘活” |
| 展示成果 | 公园品质等级图、真实步行盲区、绿视率地图、街道品质综合图、低效空间机会清单 |
| 当前适配度 | **有差异化基础**：街景绿视率/天空率 Skill 已有；公园品质和公共空间盘活需新增编排与指标规则 |

### 3.7 产业、商业与文化活力

| 项目 | 内容 |
|---|---|

| 所需数据 | 企业注册、产业用地、POI、商业建筑面积、品牌与门店、文化设施与活动、客流/热力、轨道站点、人口画像 |
| 核心方法 | 分类统计、KDE、DBSCAN、混合度、时序活力、设施—人群耦合、商圈分区 |
| 分析目的 | 识别主导产业、特色簇群、业态同质化、消费转化不足和交通—商业错配 |
| 展示成果 | 产业/商圈热点图、簇群中心、业态结构卡、日夜活力图、四象限错配区和招商/运营建议 |
| 当前适配度 | **热点与聚类已具备**；企业趋势、业态混合和时空消费建议新增专题 Skill |

### 3.8 更新潜力与规划行动优先级

| 项目 | 内容 |
|---|---|
| 具体分析 | 综合建筑年代/质量、开发强度、功能单一、土地权属、更新项目、活力、公服短板、交通可达、规划约束识别低效潜力用地；近期/中远期分级；按更新、微改造、设施补齐、公共空间盘活等形成行动类型 |
| 所需数据 | 地块、权属、用地、建筑、更新项目、规划控制线、人口活力、公服短板、交通和公共空间数据 |

| 当前适配度 | **建议作为旗舰新 Skill**：现有工具能支撑底层计算，但需专业指标体系和流程编排 |

## 4. 通用分析能力与专业规划 Skill 的展示分工

### 通用分析层：让评委看到 AI 不是固定按钮

- 自动识别上传数据的图层、字段、几何类型、坐标系、空值和空间范围。
- 根据问题动态组合统计、筛选、空间连接、缓冲、覆盖、最近距离、KDE、聚类、等时圈和图表。
- 支持自然语言追问，例如“只看老年人口”“把步行改成骑行”“按社区排名”“为什么这个区是短板”。
- 每个数字关联数据源、参数、Tool Trace、结果图层和计算口径。

### 专业规划 Skill 层：让评委看到 AI 懂规划方法

- 能判断静态半径与真实路网可达的适用差异。
- 能按设施层级、服务标准、目标人群和人口需求计算，而不是只数 POI。
- 能做服务公平、供需错配、功能混合、活力耦合、品质分级、住房负担和更新潜力。
- 能把结果翻译为规划语言：盲区、错配区、低效区、潜力区、行动类型和优先级。
- 能清楚说明假设、阈值和局限，并允许用户修改参数后重算。

## 5. 比赛推荐：1 条主线 + 5 个展示模块

### 推荐主线

> **从“高需求人群的服务短板”出发，解释空间原因，并模拟一个设施/公共空间改善方案。**

### 五个模块的优先级

| 优先级 | 模块 | 现场问题示例 | 展示亮点 | 建议状态 |
|---|---|---|---|---|
| S | 公服公平与 15 分钟生活圈 | “哪些高密度居住区 15 分钟内无法到达公园和文化设施？” | 静态圆与真实路网对照、覆盖人口、服务盲区、证据链 | 当前即可作为主线 |
| S | 人群—设施供需错配 | “设施很多，为什么这里仍是短板？” | 高需求低供给/低需求高供给四象限，规划解释明显 | 现有供需工具基础上增强分区输出 |
| A | 时空活力与功能混合 | “这里白天很热闹，为什么晚上没有活力？” | 昼夜切换、POI 混合度、活力与功能耦合 | 建议新增轻量 Skill |
| A | 公共空间与步行品质 | “哪些街道绿视率低且连接公园困难？” | 街景 AI + GIS 可达性，差异化强 | 预计算街景，现场做组合分析 |
| A | 更新潜力与方案模拟 | “优先改哪几处？新增一个设施能改善多少？” | 从诊断闭环到行动，最能体现专业价值 | 建议作为旗舰新 Skill |

产业商业、住房可负担性和全面建筑形态适合做备用追问或第二套案例，不建议在 3–5 分钟主线中全部展开。

## 6. 推荐的现场对话脚本

1. **主问题**：
   > 帮我识别研究范围内公共服务最薄弱的高需求社区，重点看公园、文化和体育设施，按真实步行 15 分钟计算。

2. **追问一：对比口径**
   > 为什么 500 米服务半径看起来覆盖很好，但 5 分钟步行仍有盲区？

3. **追问二：解释原因**
   > 把这些盲区与人口密度、老年人口、道路阻隔、POI 混合度和轨道站点叠加，解释主要原因。

4. **追问三：形成行动**
   > 从低效公共空间和老旧地块中推荐 3 个优先改善点，并说明每个点适合补什么功能。

5. **追问四：方案模拟**
   > 假设在第 1 个点新增一处社区综合服务设施，重新计算 10/15 分钟覆盖人口和短板社区变化。

这条链可以完整展示：数据就绪检查、Agent 规划、GIS 真计算、专业 Skill、地图图层、数字结果、解释、继续追问和方案重算。

## 7. 当前能力对照与实施分档

### A. 仓库中已有，优先直接展示

- 数据就绪性检查与图层管理。
- 覆盖率、缓冲、空间叠加、最近距离、密度、供需匹配。
- 真实路网等时圈与 15 分钟生活圈。
- 核密度、DBSCAN/K-Means 空间聚类。
- 街区城市体检、公共服务设施评估、15 分钟生活圈 Planning Skills。
- 街景绿视率与天空可视因子 Skill（依赖外部街景与模型，建议预计算）。
- Plan、Trace、地图结果、指标卡和证据链。

### B. 复用现有工具，补少量编排即可展示

- 人口画像与重点人群专题。
- 高需求—低供给四象限和社区短板排名。
- 轨道覆盖—商业/文化密度错配。
- 公园品质规则评分与公共空间盘点。
- POI 功能混合度和活力关联。

### C. 建议新增专业 Skill

- `urban_morphology`：用地、建筑、开发强度、混合度与活力解释。
- `population_vitality`：人口画像、职住、OD 和昼夜/周末活力。
- `livability_affordability`：住房结构、老旧程度、房价收入比和租金收入比。
- `public_space_quality`：公园品质、街道品质与低效空间盘活。
- `renewal_potential`：约束识别、多因子评分、行动分型和情景模拟。

## 8. 方法口径与专业可信度注意事项

1. **静态服务半径不能等同真实可达性**：现场最好并列展示圆形缓冲与路网等时圈，突出河流、快速路、围墙、出入口等阻隔。
2. **设施数量不能代表服务能力**：数据若有等级、容量、开放时间和收费属性，应进入供给侧权重。
3. **POI 混合度应采用规范公式**：建议使用 `H = -Σ(pᵢ ln pᵢ)`，跨区域比较时再除以 `ln(N)` 标准化。原报告公式版面中未显示负号，产品内应明确修正。
4. **“活力源代码”只能解释关联，不能直接声称因果**：容积率、建筑密度、POI 等与活力的叠加比例是相关关系；如需更强解释，应加入空间回归、控制变量或 SHAP，并标注模型局限。
5. **权重必须透明可改**：街道品质、宜居性、更新潜力等综合指数需展示指标、标准化方式、权重和敏感性。
6. **覆盖率必须说明分母**：研究范围面积、居住用地面积、居住人口或目标人群会得到不同结论。
7. **数据偏差必须进入证据链**：手机信令、平台热力、POI、房价和街景都有时间、覆盖和样本偏差，应显示数据日期、来源、缺失率与适用范围。

## 9. 最终建议

如果比赛只能重点打磨两个专业 Skill，建议选择：

1. **公共服务公平与 15 分钟生活圈**：高频、成熟、易理解、真 GIS 结果稳定。
2. **更新潜力与方案模拟**：从“会分析”升级为“能辅助规划决策”，最能形成差异化。

中间用通用分析工具串联人口密度、KDE、供需错配、最近距离、空间叠加和街景品质，即可完整体现 UrbanScope AI 的产品定位：

> **不是替规划师画一张图，而是把规划问题自动组织成可执行、可验证、可继续推演的专业分析过程。**
