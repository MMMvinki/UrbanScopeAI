# 公共服务设施资源画像

## 何时使用

当用户要在候选研究范围内分析公共服务设施（教育/医疗/体育/便民与应急等）的数量、类别构成与空间分布，或提出“分析公共服务设施”“看看教育、医疗、体育和便民设施的分布”“根据已有数据做尽可能完整的现状分析（含公共设施板块）”时，调用 `execute_skill_script` 并指定 `skill_id=public-service-profile`。这是一个只依赖 POI 全量原始总表与候选研究范围的受控确定性 Skill。

## 固定方法

- **主输入是深圳市 2024 POI 全量原始总表**（原始文件），经“四域大类筛选 → 候选研究范围筛选 → 大中小类纳入/排除 → 100m 网格统计 + 设施密度平滑多档渐变”得到结果。`01-加工数据/POI分类切片` 的 Shapefile 不作为输入；只可作为可选 `crosscheck_dir` 交叉核对派生数量，或视为由主表重新生成的缓存。
- 不使用 PPT/PDF 历史报告中的任何数字、地图或结论作为输入、目标值或验收基准。
- 研究范围为 EPSG:4326；总表坐标使用 `lon_wgs84/lat_wgs84`（EPSG:4326）；计算统一到 EPSG:32650（适合深圳），输出回 EPSG:4326。
- 先按 `bigType∈{公共设施, 科教文化服务, 医疗保健服务, 体育休闲服务}` 取四域大类记录，再做研究范围空间筛选。
- 网格固定为 100m（2026-09 起与其他板块同锚点 100m 稳定网格，数字与旧 500m 版不可横比），以米制坐标 `(0,0)` 为全局锚；格心落入研究范围的单元进入结果，`cell_id=g_<floor(E/100)>_<floor(N/100)>`。
- 对候选范围内每条记录，仅按 `midType`/`smallType` 类别字段归入“类别纳入清单”的四大功能组：
  - 教育文化：学校、博物馆、展览馆、美术馆、图书馆、科技馆、文化宫、档案馆；
  - 医疗健康：综合医院、专科医院（整形美容除外）、诊所、疾病预防机构；
  - 体育活动：运动场馆、高尔夫相关；
  - 便民与应急：公共厕所、报刊亭、公用电话、紧急避难场所。
- 明确排除或单列：一般培训机构、驾校、药店与医疗用品销售、医疗美容（整形美容）、宠物医疗、酒吧/KTV/网吧/棋牌/游戏厅等娱乐消费场所、影剧院、休闲/度假场所、传媒/科研/会展/文艺团体等机构类别，以及无法细分到可判定设施的泛化/顶层类别。
- 同时保留“原始 POI 数量”与“规划分析纳入数量”；纳入点按格心入区网格计数，输出每格总数、四类数量、类型丰富度（覆盖四大类中的几类），并以“有设施格数量中位数”划分资源相对较多/相对较少，另列无设施格。
- 稀疏设施点另做密度平滑：固定带宽 300m 高斯核摊到邻格（截断 3σ=900m，输出个/km²）；距任何设施 >900m 的格保持 0，保留“无设施”档，不把空区渲染成伪 0 连续面。

## 默认输入与参数

- `cell_size_m=100` 是固定口径，传其他值会失败。
- `poi_path`（主表）、`study_area_path` 等路径参数可替换；`crosscheck_dir` 可选。
- 文件、字段、编码、CRS、范围内有效样本或类别规则不满足契约时必须返回 `success=false`。

## 输出与解释边界

输出真实 100m 多边形图层（含设施密度平滑估计列）与范围内四功能组设施点图层；附纳入/排除数量与原因、四大功能组数量、每格统计与相对分型、无设施格与资源相对较少格、主表哈希与血缘、CRS 转换链、类别纳入清单与限制说明。证据中包含原始文件路径、原始文件哈希、使用字段、分类规则、原始记录数、范围内记录数、纳入与排除数量。

必须明确：资源相对较少只表示当前 POI 下的相对空间现象，不构成设施短缺或规划缺口；不推断设施公办或民办（POI 无法证明产权与运营主体）；POI 点位数不是独立建筑物数、容量、品质或利用率；本 Skill 不做 15 分钟生活圈、真实步行可达、覆盖人口、供需平衡、补建优先级或因果结论。
