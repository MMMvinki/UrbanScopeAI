# 活动时序画像

## 何时使用

当用户要在乐活大道候选研究范围内分析日间、夜间、工作日和周末的**相对活动强度**与昼夜节律时，调用 `execute_skill_script`，并指定 `skill_id=activity-temporal-profile`。这是一个只依赖活动数据、不涉及商业数据的受控确定性 Skill。

## 固定方法

- 默认输入只使用候选研究范围和 `gcj02_to_wgs84` 活动候选 CSV；不读取 `*_activity_type` 派生答案、历史供需层或报告结论。
- 研究范围和活动交换坐标为 EPSG:4326；计算统一到 EPSG:32650，输出回 EPSG:4326。
- 网格固定为 100m，以米制坐标 `(0,0)` 为全局锚；格心落入研究范围的单元进入结果，`cell_id=g_<floor(E/100)>_<floor(N/100)>`。
- 同一稳定格内多个活动源点取算术平均作为该格日间/夜间活动值；零值与缺失分开，缺失归 `ND`。
- 日间、夜间阈值分别为有效（非缺失）活动格的中位数；等于阈值归“高”。
- 昼夜节律分型：`D_H_N_L` 昼高夜低、`D_L_N_H` 昼低夜高、`D_H_N_H` 全天较高、`D_L_N_L` 持续较低、`ND` 无数据。

## 默认输入与参数

- `time_scope=all`；也可显式传 `wd` 或 `we`，但昼夜必须来自同一组字段。
- `cell_size_m=100` 是固定口径，传其他值会失败。
- 两个路径参数可替换，但文件、字段、几何、CRS 或空间重叠不满足契约时必须返回 `success=false`。

## 输出与解释边界

输出一个真实 100m 多边形图层、日/夜活动值、日/夜阈值、五类节律统计（每类网格数与面积）、有效格与无数据格数量、输入哈希、CRS 转换链和限制说明。

必须明确：活动强度不是人口数量；不能推导年龄、收入、职业或消费人群；不能因活动低就判断空间品质差；当前 `gcj02_to_wgs84` 仅是候选坐标转换版本，尚未获数据所有者权威确认。结果只表示日间与夜间的相对高低节律，不证明任何因果。
