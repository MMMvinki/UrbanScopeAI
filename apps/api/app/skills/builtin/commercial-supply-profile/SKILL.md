# 商业供给格局

## 何时使用

当用户要在乐活大道候选研究范围内分析商业供给的数量、密度与空间集聚、识别相对高供给和低供给区域时，调用 `execute_skill_script`，并指定 `skill_id=commercial-supply-profile`。这是一个只依赖商业数据、不涉及活动数据的受控确定性 Skill。

## 固定方法

- 默认输入只使用候选研究范围和商业原始专题点源；不读取 `*_activity_type` 派生答案、历史供需层或报告结论。
- 研究范围为 EPSG:4326；商业源必须由文件元数据证明为 EPSG:4547；计算统一到 EPSG:32650，输出回 EPSG:4326。
- 网格固定为 100m，以米制坐标 `(0,0)` 为全局锚；格心落入研究范围的单元进入结果，`cell_id=g_<floor(E/100)>_<floor(N/100)>`。
- 商业先过滤 `isdelete=0`，按点所在网格计数；商业密度单位为个/km²（数量 / 0.01）。
- 商业阈值为研究范围内正密度网格的中位数；等于阈值归“高供给”。

## 默认输入与参数

- `cell_size_m=100` 是固定口径，传其他值会失败。
- 两个路径参数可替换，但文件、字段、几何、CRS 或空间重叠不满足契约时必须返回 `success=false`。

## 输出与解释边界

输出一个真实 100m 多边形图层、商业点数量、密度、高低供给分类与阈值、各类网格数与面积、商业数据从原始记录到最终入格的数量变化、输入哈希、CRS 转换链和限制说明。

必须明确：商业点数量不等于营业额；不能判断经营好坏；不能推断消费等级或完整业态结构；商业密度是相对供给强度，不能直接称为商业繁荣度。结果只描述商业供给的相对高低，不证明任何因果。
