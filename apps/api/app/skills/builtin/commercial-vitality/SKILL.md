# 商业供给 × 昼夜活力

## 何时使用

当用户要在乐活大道候选研究范围内分析商业供给与日间、夜间活力的空间匹配、错位或昼夜节律时，调用 `execute_skill_script`，并指定 `skill_id=commercial-vitality`。这是一个受控、确定性的主场景 Skill，不拆成通用 GIS 工具自由试探。

## 固定方法

- 默认输入只使用候选研究范围、商业原始专题点源和 `gcj02_to_wgs84` 活力候选 CSV；不读取历史“商业供需”“设施密度”或 `*_activity_type` 派生答案。
- 研究范围和活力交换坐标为 EPSG:4326；商业源必须由文件元数据证明为 EPSG:4547；计算统一到 EPSG:32650，输出回 EPSG:4326。
- 网格固定为 100m，以米制坐标 `(0,0)` 为全局锚；格心落入研究范围的单元进入结果，`cell_id=g_<floor(E/100)>_<floor(N/100)>`。
- 商业先过滤 `isdelete=0`，按点所在网格计数；商业密度单位为个/km²。
- 商业阈值为研究范围内正密度网格的中位数；昼、夜阈值分别为有效活力网格中位数；等于阈值归“高”。
- 输出并列保存 `supply_day_quadrant`、`supply_night_quadrant`、`day_night_type`，缺活力的格网为 `ND`，不进入四象限分母。

## 默认输入与参数

- `time_scope=all`；也可显式传 `wd` 或 `we`，但昼夜必须来自同一组字段。
- `cell_size_m=100` 是固定口径，传其他值会失败。
- 三个路径参数可替换，但文件、字段、几何、CRS 或空间重叠不满足契约时必须返回 `success=false`。

## 输出与解释边界

输出一个真实 100m 多边形图层、三组分类统计、阈值、输入哈希、过滤数量、CRS 转换链、优先核查网格和限制说明。结果只表示空间共现与相对高低，不能证明商业导致活力，也不能推导“减少/增加多少店即可改变人流”。当前 `gcj02_to_wgs84` 仅是候选转换版本，输出必须保留“尚未获数据所有者权威确认”的限制。
