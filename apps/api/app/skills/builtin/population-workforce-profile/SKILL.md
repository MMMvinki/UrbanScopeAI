# 人口·就业画像

## 何时使用

当用户要在乐活大道候选研究范围内分析居住人口与就业人口的空间分布、数量与职住比、年龄/学历/收入/消费等结构，或提出「分析人口画像」「看看人口结构和就业分布」「青年/高学历/中高收入人群在哪里集聚」时，调用 `execute_skill_script` 并指定 `skill_id=population-workforce-profile`。这是一个只依赖常住数量（居住/工作）+ 常住画像（居住/工作）四份原始 TXT 与候选研究范围的受控确定性 Skill。

## 固定方法

- **主输入是四份原始 TXT**：`常住分析/常住数量/居住数量.txt`、`工作数量.txt`（人口类型=home/work，人数），`常住分析/常住画像/居住画像.txt`、`工作画像.txt`（网格级 `维度:取值` 比例列）。不使用 PPT/PDF 中的人口数字、地图或结论作为输入、目标值或验收基准。
- **坐标契约（数据事实来源 66/67 已核验）**：原始网格中心坐标一律按 GCJ-02 读入，执行标准 GCJ02→WGS84（复用现成同款函数，与 `_gcj02_to_wgs84.csv` 逐点残差 < 1.3 m）→ 得 WGS84≈CGCS2000 真实地面 → 用候选研究范围（EPSG:4326）做格心 `within` 裁剪 → 需要米制时再转 EPSG:32650。**禁止**把原始坐标直接当 WGS84、或按 BD09 纠偏（会系统性偏 0.5–1.2 km）。
- **日期口径**：居住/工作/画像均为单一 `202604`（2026-04 单月快照）；不与客流/OD（2025 各日）横比成同一时间。
- 研究范围为 EPSG:4326；计算统一到 EPSG:32650，输出回 EPSG:4326。
- 网格固定为 100m，以米制坐标 `(0,0)` 为全局锚；`cell_id=g_<floor(E/100)>_<floor(N/100)>`，凡承载任一在范围内原始网格中心的 100m 单元进入结果。
- 职住比 = 就业人口 ÷ 居住人口（`work/home`），居住为 0 的格记为无值。

## 结构口径（条件分布，不是个人调查）

画像列是网格汇总的比例（0–1），不是个人记录。结构按「人口加权条件分布」计算：

- 对某一维度 `D` 的类别 `c`，网格 `i` 的居住/就业人口数为 `P_i`、该类别比例为 `p_i(c)`，则类别 `c` 的人口加权占比 = `Σ P_i·p_i(c) / Σ P_i·(Σ_c p_i(c))`。
- 维度覆盖率 = `Σ P_i·(Σ_c p_i(c)) / Σ P_i`；缺失比例 = `1 − 覆盖率`。缺失来源：①数量网格没有画像行；②该维度的比例列加总 < 1。
- 收入/消费/人生阶段/工作/行业等维度存在约 0.03%–0.2% 的网格级加总缺口，必须按「条件分布」标注缺失比例，不当 100% 完备画像，不推断个体真实身份。

## 群体口径

- 青年 = 年龄阶段 `18-24` + `25-34`；高学历 = 教育水平 `本科及以上`；中高收入 = 收入水平 `4000~7999` + `8000~19999` + `20000及以上`（即 4000 元及以上）。
- 群体集聚基于「居住人群」口径：每格群体人数 = 居住人数 × 该群体比例之和；相对集聚区域 = 该格群体人数高于正密度格的中位数。

## 默认输入与参数

- `cell_size_m=100` 是固定口径，传其他值会失败。
- 五个路径参数可替换，但文件、字段、编码、坐标、CRS 或空间重叠不满足契约时必须返回 `success=false`。

## 输出与解释边界

输出真实 100m 多边形图层、居住/就业人口与职住比、各维度结构条件分布（标注缺失比例）、青年/高学历/中高收入群体占比与相对集聚区域、数据日期与候选范围、估算口径、输入哈希、CRS 转换链与限制说明。证据中包含原始文件路径、原始文件哈希、使用字段、分类规则、原始记录数、范围内记录数、纳入与排除数量、坐标契约版本与日期口径。

必须明确：人口总数是「202604 单月快照数据口径下的估算值 + 候选范围筛选后」，在取得数据供应商「坐标为 GCJ-02 且授权展示」确认前不输出权威总量；画像属性是「网格汇总条件分布」，不是个人调查，不据此判断任何个人身份；不把常住（202604）与客流/OD（2025 各日）横比；不做 OD 流向、通勤方式/时间/距离、跨日期客流趋势，也不做收入/消费的精确个体推断。
